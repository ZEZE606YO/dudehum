# DUDEHUM — เว็บไซต์ร้านค้าออนไลน์ (Marketplace)

เว็บ e-commerce เต็มระบบ ให้ผู้ใช้ **สมัครสมาชิก → ลงขายสินค้า → ซื้อขาย → แชท → จ่ายเงินพร้อมเพย์** ได้จริง
หน้าเว็บทำด้วย HTML/CSS/JavaScript ล้วน + **backend จริงด้วย Node.js** (ใช้เฉพาะโมดูลในตัว ไม่พึ่ง npm package ภายนอก)

---

## ✨ ฟีเจอร์ทั้งหมด

### 👤 ระบบสมาชิก
- สมัครสมาชิก + **ยืนยัน OTP 6 หลักทางอีเมลจริง** (ผ่าน Brevo)
- เข้าสู่ระบบ / ออกจากระบบ
- **ลืมรหัสผ่าน** → รีเซ็ตด้วย OTP ทางอีเมล
- หน้าบัญชี: ข้อมูลผู้ใช้, แต้ม, คำสั่งซื้อ, ตั้งค่าพร้อมเพย์

### 🛒 ระบบร้านค้า
- **ลงขายสินค้าเอง** — กรอกชื่อ/ราคา/รายละเอียด + **อัปโหลดรูปจากเครื่อง** (บีบอัดอัตโนมัติ)
- หน้าร้านสไตล์ Shopee — หมวดหมู่, การ์ดสินค้า (ป้ายส่วนลด %, ราคา), **หน้ารายละเอียดสินค้า**
- **ตะกร้าสินค้า** — เพิ่ม/ลบ/สั่งซื้อทั้งหมด + ตัวเลขแจ้งเตือนบนหัวเว็บ
- **คำสั่งซื้อ** — บันทึกจริง แสดงในหน้าบัญชี
- **ถูกใจ (Favorite)** สินค้า
- ลบสินค้าของตัวเองได้

### 💬 ระบบแชท
- แชทสองทางระหว่างผู้ซื้อ-ผู้ขาย (หน้า `chat.html`)
- รายการห้องสนทนา + จำนวนข้อความที่ยังไม่อ่าน + อัปเดตอัตโนมัติ

### 💸 ระบบชำระเงินพร้อมเพย์
- ผู้ขายตั้งเบอร์พร้อมเพย์ → ผู้ซื้อสั่งซื้อ → เด้ง **QR พร้อมเพย์** ให้สแกนโอน
- **สร้าง QR เองในเครื่อง 100%** (คำนวณ payload มาตรฐาน EMVCo + CRC16 เอง, เรนเดอร์ด้วยไลบรารีที่บันเดิลไว้) — เลขพร้อมเพย์ไม่ออกเน็ต
- แสดงชื่อผู้รับเงิน + ยอด + ปุ่มยืนยันการโอน

## 🔐 ความปลอดภัย
- รหัสผ่านเข้ารหัส **scrypt** + salt สุ่มรายคน (ไม่เก็บรหัสจริง)
- Session = **cookie httpOnly** เซ็นด้วย HMAC (JS ฝั่งหน้าเว็บอ่านไม่ได้ กัน XSS)
- เทียบด้วย `timingSafeEqual` (กัน timing attack), กัน path traversal, escape กัน XSS ทุกจุดที่แสดงข้อมูลผู้ใช้
- OTP เก็บแบบ hash, หมดอายุ 10 นาที, จำกัดจำนวนครั้ง
- backend ใช้ **เฉพาะโมดูลในตัว Node.js** (http, crypto, fs, https) — ไม่มี dependency ภายนอกในฝั่งเซิร์ฟเวอร์

## ▶️ วิธีรัน
ต้องมี Node.js (v18 ขึ้นไป)
```bash
cd landing-page
npm start            # หรือ  node server/server.js
```
เปิดเบราว์เซอร์ที่ **http://localhost:5173**

> เปิดให้คนอื่นเข้าผ่านลิงก์: ดับเบิลคลิก `เปิดเว็บ.bat` + `เปิดลิงก์สาธารณะ.bat` (Cloudflare Tunnel)
> ตั้งค่าอีเมล (OTP) จริง: ดูหัวข้อ Brevo ด้านล่าง — ถ้าไม่ตั้ง จะรันโหมดทดสอบ (โชว์ OTP ใน console)

## 🧰 เทคโนโลยี
- **Frontend:** HTML5, CSS3 (design tokens, responsive), Vanilla JavaScript
- **Backend:** Node.js (โมดูลในตัวล้วน) — REST API, เสิร์ฟไฟล์ static + API ที่ origin เดียว
- **เก็บข้อมูล:** ไฟล์ JSON (`server/data/`) — ผู้ใช้, สินค้า, ตะกร้า, ออเดอร์, แชท ฯลฯ
- **อีเมล:** Brevo HTTP API · **QR:** qrcode-generator (บันเดิลในเครื่อง)
